# Fitcheck Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Fitcheck — a frontend-only, in-memory clickable prototype of a wardrobe app for a demo, on the existing Expo v54 scaffold.

**Architecture:** Native mobile app using Expo Router with a 4-tab bottom bar. All data is hardcoded in `lib/data.ts`. Wardrobe items live in a React Context so the Add Item screen mutates the same in-memory list the Wardrobe grid reads. All "AI" actions are fake: `setTimeout` + spinner. Garment images are hex-colored placeholder tiles labeled with the garment name. Outfit suggestions come from a pluggable `lib/matching.ts` returning dummy suggestions derived from the wardrobe.

**Tech Stack:** Expo ~54, Expo Router ~6, React Native 0.81, React 19, TypeScript (strict). React Native primitives + `StyleSheet` only — NO web/CSS. `@/` path alias.

## Global Constraints

- **Expo v54** — before writing any Expo/RN API, consult https://docs.expo.dev/versions/v54.0.0/ (per AGENTS.md). Do not invent APIs.
- **No backend, no persistence, no auth, no network.** All state is in-memory React state; refreshing resets everything. Intended.
- **Every "AI" action is fake:** a `setTimeout` (1500ms for Add Item analysis) with a visible spinner + text.
- **No real images.** `GarmentTile` renders a `View` with `backgroundColor` = garment hex + the name label. The `image` field is unused for now.
- **Native only.** `<View>`, `<Text>`, `<Pressable>`, `<ScrollView>`, `<TextInput>`, `StyleSheet.create`. No `div`, `img`, CSS, hover.
- **NO TESTS.** Do not create test files or add jest. Verify only with `npx tsc --noEmit`, `npx expo lint`, and a manual run.
- **TYPES/INTERFACES ARE SEPARATED (mandatory).** No `type` or `interface` may be declared inline in any component, screen, lib, or data file. Every `type` alias lives in a root **`types/`** folder; every `interface` lives in a root **`interfaces/`** folder. Files are named by module (see the module map in Task 1). All consumers import from `@/types/*` and `@/interfaces/*`. Inline prop annotations like `({ x }: { x: number })` are forbidden — declare `interface FooProps` in `interfaces/foo.ts` and import it.
- **Palette (`constants/design.ts`):** cream bg `#F7F1E8`, surface `#FFFDF9`, charcoal text `#2E2A26`, muted `#8A8178`, terracotta accent `#C56B4A`, success `#4F8A5B`, warn `#C98A2E`, chip `#EFE7DA`. Radii 16–20, soft shadows, 16–24px spacing.
- **TypeScript strict** — no `any`.

**Git:** Commit locally after each task. Do NOT push to any remote.

- [ ] **Step 1: Create `lib/matching.ts`**

```ts
import { Garment } from '@/interfaces/garment';
import { Outfit } from '@/interfaces/outfit';
import { Occasion } from '@/types/garment';

const REASONS = [
  'Neutral tones, office-appropriate',
  'Relaxed weekend pairing',
  'Smart-casual, easy to dress up',
];

// DUMMY: pairs first available top/bottom/shoes into up to 3 outfits.
// Real algorithm (color harmony + formality proximity) replaces this body later;
// signature and Outfit shape stay identical.
export function generateOutfits(items: Garment[]): Outfit[] {
  const tops = items.filter((g) => g.category === 'top');
  const bottoms = items.filter((g) => g.category === 'bottom');
  const shoes = items.filter((g) => g.category === 'footwear');
  const count = Math.min(3, tops.length, bottoms.length, shoes.length);
  const outfits: Outfit[] = [];
  for (let i = 0; i < count; i++) {
    outfits.push({
      id: `o${i + 1}`,
      top: tops[i], bottom: bottoms[i], shoes: shoes[i],
      score: 92 - i * 7,
      reason: REASONS[i % REASONS.length],
    });
  }
  return outfits;
}

export function shopMatches(items: Garment[], targetOccasion: Occasion): Garment[] {
  return items.filter((g) => g.occasions.includes(targetOccasion));
}
```

```tsx
import { createContext, useContext, useMemo, useState } from 'react';
import { GARMENTS } from '@/lib/data';
import { Garment } from '@/interfaces/garment';
import { WardrobeValue, WardrobeProviderProps } from '@/interfaces/wardrobe';

const WardrobeContext = createContext<WardrobeValue | null>(null);

export function WardrobeProvider({ children }: WardrobeProviderProps) {
  const [items, setItems] = useState<Garment[]>(GARMENTS);
  const value = useMemo<WardrobeValue>(
    () => ({
      items,
      addItem: (g) => setItems((prev) => [{ ...g, id: `u${Date.now()}` }, ...prev]),
    }),
    [items],
  );
  return <WardrobeContext.Provider value={value}>{children}</WardrobeContext.Provider>;
}

export function useWardrobe(): WardrobeValue {
  const ctx = useContext(WardrobeContext);
  if (!ctx) throw new Error('useWardrobe must be used within WardrobeProvider');
  return ctx;
}
```

import { View, Text, StyleSheet } from 'react-native';
import { GarmentTileProps } from '@/interfaces/garment-tile';
import { radii, spacing } from '@/constants/design';

function isLight(hex: string) {
  const h = hex.replace('#', '');
  const r = parseInt(h.slice(0, 2), 16), g = parseInt(h.slice(2, 4), 16), b = parseInt(h.slice(4, 6), 16);
  return 0.299 * r + 0.587 * g + 0.114 * b > 150;
}

export function GarmentTile({ garment, height = 120 }: GarmentTileProps) {
  const light = isLight(garment.color);
  return (
    <View style={[styles.tile, { backgroundColor: garment.color, height }]}>
      <Text style={[styles.label, { color: light ? '#2E2A26' : '#FFFFFF' }]} numberOfLines={2}>
        {garment.name}
      </Text>
    </View>
  );
}

import { useState } from 'react';
import { View, Text, Pressable, ScrollView, StyleSheet } from 'react-native';
import { SafeAreaView } from 'react-native-safe-area-context';
import { useWardrobe } from '@/lib/WardrobeContext';
import { Spinner } from '@/components/fitcheck/Spinner';
import { GarmentTile } from '@/components/fitcheck/GarmentTile';

import { Garment } from '@/interfaces/garment';

  name: 'Rust Corduroy Overshirt', category: 'top', color: '#B5643C', formality: 3,
